# ClassRelay 실제 장비 검증표

[English](acceptance.md)

자동 테스트는 실제 화면 송수신, WebSocket 복구, Windows 잠금 검증을 대체하지 않는다. 아래는 운영 전 수행할 검증이며 기본 상태는 미실시다.

| 단계 | 수행 | 합격 기준 |
|---|---|---|
| 1대 | 강사+학생, 서로 다른 Wi-Fi | 화면 선택 후 학생에 영상 표시 |
| 1대 | 인증 WebSocket 확인 | 연결 직후 상태 수신, 정상 동작에서 REST 상태 폴링 없음 |
| 1대 | 전체화면 송출→실습 | 연결된 학생이 push된 실습 명령 직후 전체화면 해제 |
| 1대 | 입력 잠금→실습 | 입력 복구, 잔류 창/키 억제 없음 |
| 1대 | 학생 Wi-Fi 끄기 | 마지막 유효 제어 상태 이후 약 15초 안에 해제 |
| 1대 | 강사 강제 종료 | 강사 lease 만료 후 학생 해제 |
| 1대 | 학생 렌더러 종료 | native watchdog 유지 및 잠금 해제 |
| 1대 | 비상 단축키 | 즉시 해제, 같은 revision으로 재잠금 없음 |
| 1대 | 망 단절 뒤 재연결 | 새 상태 적용, 만료·비상 해제 revision으로 재잠금 없음 |
| 1대 | 잠든 PC 깨우기 | 과거 잠금 적용 없이 새 push 상태 연결·수신 |
| 1대 | 로그아웃/로그인 | 설정된 Agent 자동 시작 및 연결 |
| 인증 | 잘못된 토큰·다른 학생 세션 접근 | 401/403, 제어 변경 없음 |
| 3대 | Wi-Fi·모바일 핫스팟 혼합 | 개별 장애가 다른 학생에게 영향 없음 |
| 10대 | 반복 송출/실습, 1시간 | 즉시 명령 전달과 스트림/프로세스 증가 없는 안정적 복구 |
| 30대 | 5시간 soak, 반복 해제 및 재연결 | 잠금 잔류 없음, Realtime·Workers·Durable Objects 사용량 기록 |
| 망 제한 | UDP 제한 환경 | TURN 활성화 후 연결 확인 |

테스트는 회사 소유 교육 장비에서 비상 해제 방법을 현장 담당자에게 안내한 후 실시한다. 30대 배포 전에 적어도 1대에서 강제 종료·망 단절을 실제로 검증한다. 이 PoC에서는 실계정 배포나 실제 장비 검증을 아직 수행하지 않았다.
